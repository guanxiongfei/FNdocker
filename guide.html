一、这是什么

一个纯前端工具，帮助你为飞牛 FnOS（及其他 NAS / Linux 主机）快速生成 Docker 部署文件。内置 20 个高频应用（下载、影音、网盘、笔记、运维等），支持：

应用分组自定义应用拖拽排序 删除应用/分组昼夜主题端口/路径自定义 compose + docker run

图 1：三栏工作流——左侧选应用分组，中间配置参数，右侧实时生成命令

二、快速开始（3 步）

  1. 选应用：在左侧分组中点击应用芯片（高亮即选中），支持搜索框按名称/类别过滤。
  2. 改参数：在中间「应用配置」里按需修改主机端口、映射路径后缀、环境变量。
  3. 取命令：右侧切换 docker-compose.yml / docker run 标签页，点「复制当前」或「下载 compose」。
提示：全局「主机 IP」「数据根目录」会影响所有应用的访问地址与卷映射基准路径；勾选「将端口绑定到指定主机 IP」后，compose 端口会写成 192.168.1.100:8080:8080 形式。

三、应用分组与筛选

应用默认归为四类，分组标题处可操作：

  • 影音娱乐下载 / 媒体类（qBittorrent、Jellyfin、Immich …）
  • 文件管理网盘 / 文件类（Alist、Nextcloud、File Browser）
  • 生产工具运维 / 工具类（Home Assistant、Vaultwarden、Portainer …）
  • 其他其余（如 Heimdall 导航页）

每个分组头部有：

  • 删除分组：删除该分组；组内自定义应用被删除，内置应用自动回到其默认分组。
  • + 自定义应用：在该分组下新增一个自己的应用（见第四节）。
  • 分组底部 + 添加分组：新建一个空分组（可改名、可删）。
图 2：分组头部提供「+ 自定义应用」与「删除分组」操作

四、自定义应用

点分组头部的 + 自定义应用（或自定义应用芯片上的 ✎）打开弹窗，可编辑：

  • 应用名称：显示用名称。
  • 镜像地址：如 linuxserver/qbittorrent:latest。
  • 容器端口：可增删，含协议（tcp/udp）与「Web」开关（用于生成访问地址）。
  • 路径映射：每行「容器路径 + 映射后缀」，最终路径为 数据根目录/映射后缀。
  • 环境变量：可增删键值对。
图 3：自定义应用弹窗——名称、镜像、端口、路径、环境变量均可配

五、拖拽排序与跨组移动

每个应用芯片可拖动：

  • 在同一分组内上下拖动 → 调整顺序。
  • 拖到另一分组的芯片区域 → 移动过去（图 4）。
  • 芯片上的 × 删除该应用；✎（仅自定义应用）编辑。
图 4：把「Jellyfin」从影音娱乐拖到文件管理
所有排序、分组、删除、自定义应用与全局设置都会自动保存在浏览器本地（localStorage），刷新页面不丢失；内置应用的删除仅本次会话内有效，刷新会恢复。

六、昼夜主题

右上角按钮在 ☀️ 白天 / 🌙 黑夜 间切换，标题栏与全站配色随之变化，选择会被记住。

图 5：右上角主题切换按钮

七、生成 compose 与 docker run

右侧结果区有两个标签页：

  • docker-compose.yml：合并所有选中应用，含 services 与共享网络 fnos_net。多服务应用（如 Immich 的 server/db/redis）会自动互联。
  • docker run：每个服务生成一条 docker run 命令，并附带访问地址注释。结果按应用名自动排序，长命令自动换行，不会撑宽页面。

操作：复制当前 复制当前标签页文本；下载 compose 导出 docker-compose.fnos.yml。

在飞牛 / 主机上部署：
① 保存为 docker-compose.yml 后执行 docker compose up -d；
② 或逐条执行 docker run …（脚本已自动创建 fnos_net 网络）。

八、访问你的服务

部署后，按「主机 IP + Web 端口」访问，例如默认 http://192.168.1.100:8080（qBittorrent）。若勾选了「端口绑定到指定主机 IP」，请确认该 IP 是本机在该网络中的实际地址。

本工具只在浏览器本地生成配置，不会上传任何数据。
